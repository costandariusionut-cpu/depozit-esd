# Depozit ESD

Aplicația de inventar, evenimente și închirieri a echipei ESD (Event Sound DJ).

- Adresă: https://costandariusionut-cpu.github.io/depozit-esd/
- Se instalează pe telefon din browser: iPhone – Safari → Partajare → „Adaugă pe ecranul principal"; Android – Chrome → meniu → „Instalează aplicația".
- Datele echipei nu sunt în acest depozit de cod; ele stau într-o bază de date separată, la care se ajunge doar cu codul de echipă.

Fișierele de aici sunt generate automat din sursa proiectului (`unelte/build-app.py`); nu se modifică de mână.
